# evalkit 开发汇报

> 日期：2026-08-19
> 状态：题库试卷化 + 实测回填基本完成；机器预判评估器（组合规则树）待实现。

## 一、项目定位

多 Agent（claude / codemaker）× 多模型批量评测平台，面向「远程 Windows PC 自动化」领域。
以一整张能力卷（L1-L4）为题库：跑测 → 统计总览（SR + 置信下界）→ 人工复核/答辩。

---

## 二、本轮完成

### 1. 题库试卷化（M5）
- 题库权威源迁移到 `papers/*.yaml`（git 管理）；SQLite `tasks` 表存导入快照，服务启动自动导入。
- 题目 schema 扩展：`title / expected_answer / tools_required / accept_criteria / device_var / prep / version / enabled`。
- 共 **23 题**：L1 6 + L2 6 + L3 uu 3（已安装取号 / 卸载 / 未安装取号）+ L3 g66 1 + L3-S 2 + L4 5。

### 2. 机器预判组合规则树（设计）
- 判据从「关键词锚点」升级为 `all / any / not` 组合规则树 + 8 种原子条件
  （`tool_called / tool_result / tool_ok / tool_success_rate / tool_fail_zero / text_contains / metric / file_exists`）。
- 三条硬证据：**模型最终 content + 整个工具调用链 + 工具调用成功率**。
- 关键结论：L4 工具失败是预期、不计工具成功率；命令名只作参考、硬证据是工具输出的结果关键词。

### 3. 实测回填（claude + claude-opus-4-8）
- 用真实跑测收集 18 道题的参考答案（content + 工具链），落 `papers/references.json`。
- L1(6) + L2(6) + L3 uu(3) + L4(3：不存在设备/进程/文件) 已照实测回填。
- 过程中修正两个「凭空写」错误：connect_check 用 `list_devices`（非 `is_connected`）；文件存在用本地 `Bash`（非远程 `shell`）。

### 4. 停用未实测题
- L3 g66、L3-S ×2、L4 占用/锁屏 共 5 题标 `enabled: false`；`start_batch` 已排除停用题。

### 5. 前端优化
- **题库页**：显示实测参考结论 + 工具链（"参考"展开 / 编辑顶部面板），隐藏机器初筛；query/设备变量改整行左对齐。
- **批量评测页**：删顶部 skill 字段、删旧任务编辑器；任务多选（默认全选）+ skill/级别筛选，全选作用于筛选子集（含半选态）。

### 6. 修复与清理

- 修 `uu-remote-auto` skill 的 `dk_note_updater.py` 同款 page_size bug。
- 删除「一键生成 L1-L4」功能及整条代码链（task_gen 模板生成器、`/api/tasks/generate` 等，净删 471 行）。
