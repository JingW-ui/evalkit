# evalkit 评测系统 · 完整开发说明

> 通用 AI Agent 评测工具链：读取 Agent 会话日志/实时事件流，输出单会话评测报告、
> L1-L4 任务判级、评测矩阵；支持按模型提供商拉起 Agent 交互式终端。
> 本文档为项目开发总纲，调研报告与开发日志见同目录（docx/）。

- 项目位置：`D:\wy_projects\evalkit`
- 技术栈：Python 3.10（后端）+ React 19 / Vite 7（前端，`webui/`）
- 测试：`tests/` 10 套件（脚本式，`python tests/test_*.py` 直接运行）

---

## 1. 项目目标与能力

| 能力 | 说明 |
|------|------|
| **会话评测** | 读取会话日志/实时事件流 → 指标折叠 → 单会话报告（耗时拆分/任务/工具/成本） |
| **轨迹** | 三泳道时间线（input/model/tools），DSH 口径无缝（用户点/思考块/工具块），跨轮次等待压缩 |
| **任务判级** | L1-L4 自动判级（query 匹配 + 校验器 + 启发式兜底），结果回写评测记录 |
| **评测矩阵** | agent × L1-L4 成功率画像（`results/eval_records.json`） |
| **批量闭环** | task_gen 生成任务 → eval_batch 执行 → 判级 → 矩阵（生成→执行→判级→矩阵） |
| **拉起会话** | 按 provider（模型提供商）配置，在指定目录打开交互式 claude 终端（新窗口） |
| **多通道** | claude CLI stream-json / dsh SDK / codemaker DB / airlab 文本日志 → 统一事件流 |

## 3. 核心模块

### 3.1 统一事件流（DSH SessionEvent 同构）

事件 `{type, seq, time(epoch ms), data}`：

| type | data 要点 | 含义 |
|------|-----------|------|
| `user/message` | content[], skills?, system_injected? | 用户输入（skill_listing 带 skills 并入前一条 user） |
| `assistant/message` | message{content[], usage, model} | 模型回复（含文本/推理块） |
| `assistant/chunk` | chunk{delta, type} | 流式增量（TTFT 检测） |
| `tool/call` | name, callId, arguments | 工具调用开始 |
| `tool/result` | callId, message{content, isError} | 工具结果（未配对→未闭合块延伸标注） |
| `turn/start` / `turn/end` | turn, reason{kind} | 轮次边界（结束原因） |
| `step/start` / `step/end` | step, turn | 模型活跃段（llm_ms 累计） |
| `request/header` | header{tools, model} | 会话初始化（工具列表/模型名） |

缺 `time` 的事件（如 Claude init 行）由前端继承前一事件时间，绝不用 `Date.now()`。

### 3.2 EventMetrics（dsh_backend.py）

增量折叠器，指标：

- **耗时拆分**：`duration_ms`（首末事件）/ `llm_ms`（step 累计，无 step 通道用
  assistant→下一产出的后向间隙兜底）/ `tool_ms`（call→result）/ `human_wait_ms`
  （AskUserQuestion/question 挂起）/ 空闲 = 整体 − 三者和；
- 跨轮次长间隙归**空闲**（用户思考/离开），不计模型活跃；
- `tasks[]`：每条真实用户指令一个任务，含 `subitems`（todo 表）+ `tools`（工具链）；
- 判级 `judge` 回写（由 eval_server / eval_batch 调 `judge_eval`）。

### 3.3 通道适配

| 通道 | 适配器 | 事件来源 |
|------|--------|----------|
| claude CLI | `ClaudeEventAdapter`（claude_backend.py） | `claude --print --output-format stream-json` 逐行 |
| claude 历史 | `claude_jsonl_to_events`（tail_attach.py） | `~/.claude/projects/*/*.jsonl` 增量尾随 |
| dsh SDK | `DshEvalBackend` | DeepSeek Harness runtime 订阅 |
| codemaker | `CodemakerEventAdapter`（codemaker_backend.py） | opencode.db（session/message/part/todo/event 表） |
| airlab | `scan_airlab_log`（session_report.py） | 纯文本 pod 日志（`[HH:MM:SS] [工具]` + usage + 用时） |

### 3.4 判级与矩阵（eval_records.py）

- `judge_eval(query, session_id, metrics, assistant_text, tasks=None)`：
  query 子串匹配任务 → 校验器；无匹配 → L4 启发式 → `classify_level` 规则兜底；
  level 带 `L` 前缀（"L1"~"L4"、"L?"）；
- `EvalRecords`：`results/eval_records.json`，多进程安全（`add()` 写前重读，
  `matrix()`/`all(reload=True)` 读前重载）。

### 3.5 轨迹（webui/src/components/TrajectoryView.jsx）

对齐 DSH `deriveTimedTimeline` 口径：

- span = `[startedAt, startedAt+duration]`：消息=零宽点、工具=真实区间（call→result）、
  跨轮次等待=真实区间（投影压缩 ≤60s 等效）；
- **无缝**：assistant 消息块 = `[上一活动结束, 消息到达]`，与工具块首尾相接；
  仅含 tool_use 的消息补空 assistant/message 锚点（后端两 adapter）；
- 未闭合工具（无 result）延伸覆盖执行时间 + 「未返」虚线标注；
- `buildTimeProjection`：断裂时间轴，超长等待压缩，map/inv 往返一致（拖拽缩放安全）；
- 配色（DSH 口径）：input 蓝/灰系、model 紫、tools 绿/青/橙/黄。

### 3.6 模型提供商（provider.py）

参考 claude settings.json 的 `env` + `hooks` 结构：

- `conf.json` 的 `provider` 段（或独立 `providers.json`）声明多个 provider；
- 每个 provider：env 覆盖（`ANTHROPIC_BASE_URL/AUTH_TOKEN/MODEL` 等白名单变量）+
  hooks（PreToolUse/PostToolUse/UserPromptSubmit 等 13 事件）；
- 评测/拉起终端时合成临时 `--settings` 文件（claude 只认文件路径，拒 JSON 串）
  + env 注入子进程，不污染系统配置；用完清理。

### 3.7 前端结构（webui/）

| 文件 | 职责 |
|------|------|
| `App.jsx` | 四 tab（会话/批量/拉起/矩阵）+ SSE 路由（`_sid`）+ 批量帧一次 setState |
| `api.js` | getSessions/getProviders/startEval/attach/launchTerminal/connectSSE… |
| `exportHtml.js` | 完整所见即所得 HTML 报告导出（复用 deriveModel/deriveRows） |
| `styles.css` | DSH 暗色调色板（#0d1117/#161b22/#30363d）、细滚动条、圆角统一 |

SSE 批量帧（`batch`：events 数组 + metrics 快照）→ 前端一次 setState，
避免逐事件高频重渲染（运行中会话卡顿已修复）；事件尾部截断 3000 条。

## 4. HTTP API（eval_server.py）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/sessions?scope=all\|batch` | 会话列表（live 判定：文件 5min 内更新） |
| GET | `/api/providers` | 模型提供商列表 |
| GET | `/api/agent-status` | agent 连接状态（online/idle/offline，15s 缓存） |
| GET | `/api/raw?session_id=` | 原始日志文本 |
| GET | `/api/eval-matrix` | 评测矩阵 |
| GET | `/api/terminals` | 已打开终端列表 |
| GET | `/api/fs?path=` | 文件浏览（目录选择器） |
| GET | `/events` | SSE 帧流（run/start、batch、run/end、warning、error…） |
| POST | `/api/start` | 发起评测 `{backend, task_id, query, timeout, permission_mode, model, provider}` |
| POST | `/api/stop` | 停止当前评测 |
| POST | `/api/attach` | 挂接 `{session_id, agent, path, mode: live\|replay}`（live 文件旧→自动降级 replay） |
| POST | `/api/detach` | 解除挂接 |
| POST | `/api/terminal/launch` | 打开终端 `{cwd, provider}`（新控制台窗口） |
| POST | `/api/terminal/stop` | 结束终端 `{pid}` |
| POST | `/api/sessions/add\|rename\|remove` | 会话管理 |

## 6. 开发约定

1. **文档**：所有调研报告、开发日志、设计说明统一存 `docx/`（md 格式）；
   命名建议：`调研-<主题>.md` / `日志-YYYY-MM-DD-<主题>.md` / `设计-<主题>.md`；
2. **测试**：改动后跑 `python tests/test_*.py` 全量（脚本式，ALL PASSED）；
3. **前端**：改 `webui/src` 后 `cd webui && npm run build`（dist 按请求读取，免重启）；
   后端改动需重启 `python eval_server.py --port 8090 --session-root results/board
   --samples-dir sessions --web webui/dist`；
4. **前端硬约束**：无 emoji 图标（几何符号 ▸▾✓✗）、DSH 暗色视觉、成本显示 RMB、
   高信息密度、细滚动条、圆角统一 10px；
5. **git**：提交信息用 `feat:/fix:/refactor:/docs:` 前缀，中英皆可。

## 7. 快速开始

```bash
# 后端
python eval_server.py --port 8090 --session-root results/board --samples-dir sessions --web webui/dist

# 前端（开发时）
cd webui && npm install && npm run dev

# 批量闭环
python eval_batch.py gen --domain g66,uu_remote,airgattai,generic --out tasks/gen
python eval_batch.py run --tasks-dir tasks/gen --permission-mode bypassPermissions --session-root results/batch

# 测试
python tests/test_eval_server.py && python tests/test_claude_backend.py && ...（或逐个）
```

浏览器打开 `http://127.0.0.1:8090`：会话评测/批量评测/拉起会话/评测矩阵。
