## 二、本轮完成

### 1. 组合规则树评估器落地（核心）
- `judge_eval` 从旧「关键词锚点」升级为 `all / any / not` 组合规则树 + 8 种原子条件
  （`tool_called / tool_result / tool_ok / tool_success_rate / tool_fail_zero / text_contains / metric / file_exists`）。
- 三条硬证据：模型最终 content + 工具调用链 + 工具成功率；MCP 前缀归一化（`mcp__airgattai__shell` → `shell`）。
- 新增 `tool_called.any_of`（多工具任一命中）、`PowerShell→Bash` 别名、大小写不敏感匹配。

### 2. 评估器鲁棒性修复（跑测暴露的误判）
- L1：file_exists（Glob 判存在）、env_info（DK API 直查，未走 occupy+shell）、process_probe（「没有运行」漏词）。
- L2：occupy_push / process_manage / remote_download 的成功文案关键词过窄 → 补「推送文件 / 已落地 / 已校验 / 重新启动 / 进程重启 / 文件存在」等。
- 结论：判定应抓「结果证据」，工具名只作参考、允许等价路径。

### 3. 价格口径修复
- 统计总览/入库统一用**挂牌价估算**（`models_usd` 表），模型/平台返回的结算价虚高（deepseek 实测 3.8~7.7 倍）仅作参考。

### 4. 统计口径修复
- `matrix()` 与 `stats()` 统一：排除「task_id 不在题库」的孤儿记录 + `review_status=invalid`。
- 置信下界（95% Wilson）从成功率单元格内联改为 hover 提示，避免 n 小时「≥34%」被误读为成功率。
